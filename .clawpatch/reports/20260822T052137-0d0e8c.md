The package.json scripts run 'vite' without specifying a config path, so they will fail to find the config file. suggested regression test:
Add a CI check that runs 'npm run build' and verifies the output exists in dist/ with expected React build artifacts. Alternatively, add a basic smoke test that imports the vite config and validates it resolves correctly.

minimum fix scope:
Move src/vite.config.ts to ./vite.config.ts and update outDir to 'dist', or update all three package.json script commands to include '--config src/vite.config.ts'.

repro:
